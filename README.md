## Сборка и запуск

Нужен `clang++` с поддержкой C++17. Выполните команду из корня репозитория.

```bash
clang++ -std=c++17 -pthread lab1/main.cpp -o /tmp/ossys-lab1 && /tmp/ossys-lab1
```

Для остановки программы нажмите `Ctrl+C`.
